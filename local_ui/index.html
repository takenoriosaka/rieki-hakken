選ばなくても大丈夫です。何も選ばずに「次へ」で、ブランド全体を調べます。選ぶと、そのモデル・型番で個別に検索して絞り込みます。

写真のタグ読み取り 無料・Mac内OCR

タイトルにも説明文にも型番が無い出品は、出品写真の文字（品質表示タグ等）を Mac の中で読み取って型番を探します。料金はかかりません（読み取り済みの写真は再度読みません）

写真で傷・汚れ確認 無料・Mac内AI

利益が出る商品の写真を Mac の中の AI（Ollama）で1枚ずつ見て傷・汚れを判定し、タイトルの状態より悪ければ相場を下げて計算します。料金はかかりません（1件あたり数十秒かかります。判定済みの写真は再度見ません）。有料の Claude より見落とし・誤判定が多いので参考程度に

写真AI確認 有料・Claude API

料金がかかります（1件あたり約6〜10円・1回のリサーチの上限 1,000円）。チェックを入れたときだけ、無料の読み取りでも型番が無い出品のタグをAIで読み、利益が出る商品は写真で傷・汚れを確認して、タイトルの状態より悪ければ相場を下げて計算します。毎回オフから始まります
